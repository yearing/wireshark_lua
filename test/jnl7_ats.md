# 接口协议

## 原则

ATS和ISCS系统之间将采用网口连接进行信息交换。它们之间的数据传输是双向的， ATS系统和ISCS系统双向收发数据。

1. 当ATS重启或ISCS重启时（即通道重新激活后），双方主动向对方发送一次全体信息。
2. 如果车站（含段、场、区间）FAS火灾状态有变化，ISCS发送全部的FAS火灾信息至信号系统（ATS），如果信息在5秒钟内不变化，则也发送全部信息给SIG（ATS）系统。
3. 如果SCADA状态变化，ISCS发送全部的SCADA信息至信号系统，如果信息在5秒内不变化，也发送全部信息给信号系统。
4. 信息发送采用**变化发送**的方式，初始建立连接的时候发送全体信息，若信息改变，则立刻发送。
5. 当主机收到一条信息时，正常情况下必须立即（30ms）向发送方发送一条回执信息。数据量多时，发送回执信息时间不能超过50ms。 数据发送方接收到回执信息后，必须立即发送下一包数据。为了保证数据及时下发，数据接收方需要有每秒接收30包信息，并发送30包回执信息的处理能力。

### 数据发送原则

站台信息由ATS系统发送，站台信息最大可为未来20分钟内到站的列车发送信息。

每辆列车的规划周期为20分钟，例：每列列车都应有一个计划包含了未来20分钟制定好的运行。根据针对每列列车未来20分钟运行而生成的计划，站台信息将发送给所有列车计划中涉及到的站台。例如，系统中只有一辆列车，并且他将在首站停留1分钟，那么就有一个当前站台之后未来19分钟的列车计划。在这种情况下，如列车在1分钟后离开首站，那些列车在19分钟后未能到达的车站就不应显示该列列车。

一个站台可接受多于一辆列车的信息。根据每一列车的情况生成一个将来20分钟的运行计划，对各站台来说这是列车运行计划，站台信息将被发送给站台。站台信息中包含的各列车无到站时间先后顺序。

站台信息将在以下情况下发送：

* 如果某一重大事件影响了列车计划，如，一列列车进入或离开系统。每列列车的计划周期为未来的20分钟。
* 当站台数据变化时，会发送至ISCS。

如果没有变化情况，站台信息只发送一次。当检测到某个站台有变化信息时，ATS将发送会到达该站台的所有列车的最新信息。ISCS应使用该站台列车的最新信息。如果先前ISCS系统具有某辆车的到站信息，并且最新接收到的信息中不再包含此车，那么说明此车的计划已不包含该站台，应被移除。

### 数据发送原则

当一台主机收到一条信息时，必须向发送方发送一条回执信息。

数据发送方对所发送每一条数据均进行超时检查，ATS作为数据发送方在数据发送完成后开始计时，在未收到数据接收方的回执信息或2s超时未到前，不发送下一包数据。当超过2s没有收到对方回执信息将进行重发。重发两次（加初次发送共三次）仍没有确认则认为通讯中断。

# 通信机制

## 建立连接

ATS与ISCS系统采用4套独立的物理设备进行连接。ATS与ISCS之间有8个逻辑通信连接。

信号系统为ISCS系统提供8个IP地址，ISCS提供8个相应的端口分别对应控制中心和备用中心的ATS服务器。

ATS系统为服务端，ISCS作为客户端进行连接。ATS提供8个IP地址和8个相应的物理端口，通讯建立时ISCS应试图连接第一个IP地址，一旦连接已经建立，ISCS不会建立其他连接。但是ISCS的连接应处于备用状态，随时准备进行连接。

如果由于某种原因，ISCS与ATS的第一个IP地址的连接没有建立成功，ISCS应试图连接到其他IP地址，直到成功建立连接。

![](data:image/x-emf;base64...)

正常情况下控制中心的ATS服务器作为主用服务器，当控制中心主备ATS服务器都不可用时，系统将自动切换到备用控制中心的ATS服务器上使用。

## 信息传送

信息通过已经建立的连接进行传送。

## 保持连接

有效链接上，当无数据发送时，双方每1秒钟互发心跳信息，在3次心跳时间内没有收到任何数据或心跳信息则认为链接失效。ISCS应尝试新的连接。

## 通道故障切换处理

ATS系统作为服务器端，ISCS作为客户端进行连接。

成功建立的连接作为主用通道，其它为备用通道且未连接。ATS系统与ISCS系统通过主用通道相互发送信息。

如果主用通道连接故障，ISCS应尝试与其它的IP地址建立连接，一旦连接建立，信息通过刚刚建立的连接传送，此通道变为主用通道。

unsigned char CalCRC(unsigned char\* buf, int len, unsigned char& high, unsigned char& low)

{

int crc = 0;

for (int i = 0; i< len; ++i)

{

crc += buf[i];

}

unsigned char \_crc = crc & 0xFF;

high = \_crc/16;

low = \_crc%16;

if (high<=9)

{

high += 0x30;

}

else if (high>=10 && high<=15)

{

high += (0x41-0x0a);

}

if (low<=9)

{

low += 0x30;

}

else if (low>=10 && low<=15)

{

low += (0x41-0x0a);

}

return \_crc;
